# 环境检查与依赖下载（ROS2 Humble）

> 上位机（Humble）跑 `maping_mid360.py` 和 `nav_mid360.py` 所需依赖清单 + 下载命令。

---

## 一、依赖清单（import → Humble 包名）

### maping_mid360.py（建图 + 打点）

| Python import | Humble 包 |
|---|---|
| `rclpy` | `ros-humble-rclpy` |
| `nav_msgs` | `ros-humble-nav-msgs` |
| `sensor_msgs` | `ros-humble-sensor-msgs` |
| `sensor_msgs_py`（point_cloud2） | `ros-humble-sensor-msgs-py` |

### nav_mid360.py（导航）

| Python import | Humble 包 |
|---|---|
| `rclpy` | `ros-humble-rclpy` |
| `nav_msgs` | `ros-humble-nav-msgs` |
| `geometry_msgs` | `ros-humble-geometry-msgs` |
| `nav2_msgs.action.NavigateToPose` | `ros-humble-nav2-msgs` |

### Nav2 栈（可选，真做全局路径规划才需要）

| 包 | 作用 |
|---|---|
| `ros-humble-navigation2` | Nav2 核心 |
| `ros-humble-nav2-bringup` | Nav2 启动 |
| `ros-humble-nav2-map-server` | 加载 2D 栅格地图（map2d.yaml） |

---

## 二、下载命令（按需选）

### ① 最小安装（两个脚本 import 都能过，纯 PID 导航）

```bash
sudo apt update
sudo apt install -y ros-humble-rclpy ros-humble-nav-msgs ros-humble-sensor-msgs ros-humble-sensor-msgs-py ros-humble-geometry-msgs ros-humble-nav2-msgs
```

### ② 完整安装（加 Nav2 全局规划 + 加载 2D 栅格地图）

```bash
sudo apt update
sudo apt install -y ros-humble-navigation2 ros-humble-nav2-bringup ros-humble-nav2-map-server
```

### ③ 可选：2D SLAM 建图

```bash
sudo apt install -y ros-humble-slam-toolbox
```

---

## 三、检查命令（装完验证）

### Python import 检查

```bash
for m in rclpy nav_msgs sensor_msgs sensor_msgs_py geometry_msgs; do
  python3 -c "import $m" 2>/dev/null && echo "✅ $m" || echo "❌ $m"
done
python3 -c "from nav2_msgs.action import NavigateToPose; print('✅ nav2_msgs')" 2>/dev/null || echo "❌ nav2_msgs"
```

### Nav2 包检查

```bash
for pkg in navigation2 nav2-bringup nav2-map-server nav2-msgs; do
  dpkg -l 2>/dev/null | grep -q "ros-humble-$pkg" && echo "✅ ros-humble-$pkg" || echo "❌ ros-humble-$pkg"
done
```

## 四、结论速查

| 场景 | 最少需要 |
|---|---|
| 跑 `maping_mid360.py`（建图+打点） | rclpy + nav-msgs + sensor-msgs + sensor-msgs-py |
| 跑 `nav_mid360.py`（import 能过，纯 PID） | + geometry-msgs + nav2-msgs |

## 五、启动命令

> 前提：先 source ROS2 + 工作空间，下位机（TCP）已上电，Livox + Super-LIO 在跑。

```bash
# 通用 source（每个终端先执行）
source /opt/ros/humble/setup.bash
source ~/ws_livox/install/setup.bash
```

### ① 手动控制（hand.py，不需要定位）

```bash
python3 hand.py
# w=前进  s=后退  a=左转  d=右转  q=退出
```

### ② 底盘测试（demo_move.py，不需要定位）

```bash
python3 demo_move.py
# 1前进 2左转 3右转 4后退 5急停 0退出
```

### ③ 建图 + 打点（maping_mid360.py，需要 Super-LIO 定位）

```bash
# 先起 Livox 驱动 + Super-LIO（另开两个终端）
# 终端A：ros2 launch livox_ros_driver2 msg_MID360_launch.py
# 终端B：ros2 launch super_lio Livox_mid360.py

python3 maping_mid360.py
# g=记目标点  l=列表  q=退出保存 map3d.pcd + map2d.pgm/yaml + points.txt
```

### ④ 导航（nav_mid360.py，需要定位 + 可选 Nav2）

```bash
# 重定位模式（Super-LIO）
# 终端B：ros2 launch super_lio relocation.py

python3 nav_mid360.py
# 加载 points.txt → Nav2 规划 + PID 到达目标点
```

### 启动顺序总览

```
建图流程：  Livox驱动 → Super-LIO建图 → maping_mid360.py（g打点，q存图）
导航流程：  Livox驱动 → Super-LIO重定位 → nav_mid360.py（自动到达目标点）
手动测试：  hand.py / demo_move.py（只要下位机 TCP，不用定位）
```
