## ⏰ 时间戳格式说明

### 自动格式

所有提交都会自动添加时间戳：

```
格式: YYYY-MM-DD HH:MM:SS - 描述
示例: 2024-09-21 15:30:45 - 添加了新功能
```

### 手动格式 (不用脚本时)

```bash
# 使用这个命令
git commit -m "$(date '+%Y-%m-%d %H:%M:%S') - 你的描述"

# 输出:
# 2024-09-21 15:30:45 - 你的描述
```

## 🔄 版本回滚详解

### 回滚类型对比

| 操作 | 命令 | 保留修改 | 是否安全 | 使用场景 |
|------|------|----------|----------|----------|
| 软回滚 | `git reset --soft` | ✅ 是 | ✅ 安全 | 想重新提交 |
| 硬回滚 | `git reset --hard` | ❌ 否 | ⚠️ 危险 | 完全丢弃修改 |
| 反向提交 | `git revert` | ✅ 是 | ✅ 最安全 | 保留历史记录 |

### 使用脚本回滚 (推荐)

```bash
./git_helper.sh

# 回滚到上一版本
选择: 9

# 或回滚到指定版本
选择: 10
# 输入 commit ID (前7位)
```

脚本会:
- ✅ 显示当前和目标版本
- ✅ 要求确认操作
- ✅ 询问是否保留修改
- ✅ 询问是否立即推送
- ✅ 彩色提示和错误检查

## 🔑 认证配置

### 方式 1: Personal Access Token (推荐)

**获取 Token:**

1. 访问: https://github.com/settings/tokens
2. Generate new token (classic)
3. 勾选 `repo` 权限
4. 生成并复制 Token

**配置 Token:**

```bash
# 使用脚本 (最简单)
./git_helper.sh
选择: 19 - 配置 Token/SSH
选择: 1 - Personal Access Token
粘贴 Token

# 或手动配置
git config --global credential.helper store
# 下次推送时输入一次就保存了
```

### 方式 2: SSH 密钥 (更安全)

```bash
# 使用脚本
./git_helper.sh
选择: 19 - 配置 Token/SSH
选择: 2 - SSH 密钥

# 或手动配置
ssh-keygen -t ed25519 -C "your_email@example.com"
cat ~/.ssh/id_ed25519.pub
# 复制公钥到 GitHub: https://github.com/settings/keys
```

## 🆘 常见问题快速解决

### 问题 1: 推送失败

```bash
错误: ! [rejected] main -> main (fetch first)

解决:
git pull --rebase
git push
```

### 问题 2: 忘记提交信息

```bash
# 修改最近一次提交
git commit --amend -m "新的提交信息"
git push -f
```

### 问题 3: 不小心提交了错误文件

```bash
# 使用脚本回滚
./git_helper.sh
选择: 9  # 回滚到上一版本

# 或手动
git reset HEAD^
git add 正确的文件
git commit -m "..."
git push
```

### 问题 4: 冲突

```bash
# 拉取时提示冲突
git pull

# 手动编辑冲突文件
# 找到 <<<<<<< 和 >>>>>>> 标记
# 保留正确的内容

# 解决后
git add .
git commit -m "解决冲突"
git push
```
